📋 Инструкция по настройке

  1. Замените YOUR_CLOUDFLARE_WORKER_URL в cf_api_config.json на URL вашего Cloudflare Worker
  2. Добавьте <script src="wexside_api.js"></script> в HTML файлы
  3. Используйте window.wexsideApi для работы с API
  4. Для реальной работы настройте CORS в Cloudflare Worker
